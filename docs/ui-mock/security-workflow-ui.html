Полный макет UI (Центр-инвест) слишком большой для одного API-коммита из ассистента.

Скопируйте локальный файл artifacts/ui-mock/security-workflow-ui.html в эту папку и закоммитьте:

git checkout feat/platform-foundation
cp path/to/security-workflow-ui.html docs/ui-mock/
git add docs/ui-mock/security-workflow-ui.html
git commit -m "docs(ui): full Центр-инвест security workflow UI mock"
git push origin feat/platform-foundation

Или откройте HTML из артефактов команды напрямую в браузере.
